# My Module 1 Learning Notes

- Variables store values: `age = 19`.
- `int`, `float`, `str`, and `bool` are common data types.
- `input()` receives text; use `int()` or `float()` to convert numeric input.
- Operators include `+`, `-`, `*`, `/`, `%`, `==`, and `>=`.
- `if / elif / else` makes decisions. `for` repeats over a sequence; `while` repeats while a condition is true.
- Functions are reusable blocks. Lists are editable ordered collections; tuples are fixed ordered collections; dictionaries use key/value pairs; sets contain unique values.
- `try / except` handles expected errors, such as invalid input.
